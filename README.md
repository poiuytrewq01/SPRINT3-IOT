# CLYVO VET - Challenge Pet

Projeto da disciplina Disruptive Architectures: IoT, IoB & Generative IA - Sprint 3.

## Sobre o projeto

O CLYVO VET é a proposta de uma plataforma de cuidado contínuo do pet, pensada pra resolver três problemas: tutor esquece consulta e exame preventivo, a clínica perde o vínculo com o tutor depois da primeira visita, e não existe um histórico estruturado do pet ao longo do tempo.

A entrega dessa sprint é a definição e documentação do componente de Inteligência Artificial da solução, mais o vídeo pitch explicando a proposta.

## Tecnologia usada na abordagem de IA

API de LLM (modelo de linguagem), como a da OpenAI ou a do Google Gemini, usada pra gerar mensagens personalizadas a partir dos dados do pet. Não há implementação de código nessa sprint, o foco é a definição conceitual e a apresentação em vídeo.
